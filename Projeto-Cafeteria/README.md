# 📌 Interface Comercial – Cafeteria Moderna

> **Status do Projeto:** Concluído

### 📖 Sobre o Projeto
Esta interface comercial foi desenvolvida para simular a experiência real de um usuário ao navegar pelo cardápio, interagir com produtos e realizar o fluxo de autenticação em uma cafeteria moderna. 

Este projeto funcionou como um importante laboratório prático de fundamentos, sendo um dos meus primeiros marcos unindo HTML5 e CSS3 de forma integrada. O principal desafio técnico superado foi conciliar o aprendizado inicial e a experimentação de novas propriedades com o rigor arquitetural, garantindo um código limpo, bem indentado e com alta fidelidade estética em relação ao conceito visual proposto.

## 🛠️ Tecnologias e Conceitos Aplicados

Neste escopo, foquei em consolidar os seguintes pilares:
* **HTML5 Semântico:** Estruturação de formulários de cadastro e login utilizando validações nativas e marcação adequada.
* **CSS3 Avançado:** Aplicação de seletores, estilização de componentes de interface (menus, botões e cards) e alinhamento de elementos visuais.
* **UI/UX Design:** Uso estratégico de contraste de cores, tipografia acolhedora e hierarquia visual focada na experiência de navegação e conversão do usuário.

---

## 📁 Estrutura de Arquivos Destacada

A organização do diretório segue uma lógica clara e modular de pastas:
* `/assets`: Diretório raiz para recursos visuais e de estilo.
  * `/assets/css`: Arquivos de folha de estilo para modularização do layout.
  * `/assets/img`: Banco de mídias e imagens otimizadas para a interface.
* `index.html`: Página de entrada (*Home*) com a apresentação principal da marca e cardápio.
* `cadastro.html` / `login.html`: Páginas que compõem o fluxo essencial de autenticação do usuário.
* `mocacinno.html`: Página interna específica, desenhada para exibir os detalhes e a receita de um produto de destaque do cardápio.
