# 📌 Projeto-Cafeteria

> **Status do Projeto:** Concluído 

### 📖 Sobre o Projeto
Interface comercial desenvolvida para simular a experiência de um usuário ao navegar pelo cardápio e realizar o login em uma cafeteria moderna.

Aqui, o principal desafio foi que esse foi o meu primeiro projeto unindo html e css, então foi uma grnde oficina de testes e experiências novas e ainda sim garantil uma boa organização de código e uma boa fidadelidade estética e visual

## 🛠️ Tecnologias e Conceitos Aplicados

Neste projeto específico, foquei em exercitar:
* **HTML5:** Estruturação de formulários de cadastro/login com validações nativas e tags semânticas.
* **CSS3:** Para estilização.
* **UI/UX Design:** Aplicação de contraste de cores, tipografia legível e hierarquia visual focada na conversão do usuário.

---

## 📁 Estrutura de Arquivos Destacada

Para este escopo, a organização de pastas seguiu a seguinte lógica estrutural:
* `/assets`: Centralização de imagens e vetores utilizados na interface.
* `/assets/css`: Centralização  vetores utilizados na interface.
* `/assets/img`: Centralização de imagens utilizadas na interface.
* `index.html`: Página de entrada (Home).
* `cadastro.html` / `login.html`: Fluxo de autenticação do usuário.
* `mocacinno.html`: Página de receita de um produto da cafeteria.
