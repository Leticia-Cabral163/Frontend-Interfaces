# 📌 Portfólio de Acervo Artístico

> **Status do Projeto:** Concluído (MVP - Mínimo Produto Viável)

### 📖 Sobre o Projeto
Esta interface foi projetada para atuar como um acervo digital, centralizando e organizando produções artísticas e desenhos autorais desenvolvidos ao longo da minha formação em Artes Visuais. O projeto foi concebido sob uma restrição de tempo (*timebox*) para atender a critérios de avaliação da disciplina de Programação Web. Por esse motivo, a engenharia do projeto focou na entrega de um escopo essencial funcional e estruturado, priorizando os requisitos críticos de entrega.

O principal desafio estético e técnico foi encontrar uma identidade visual e um layout que traduzissem a sensibilidade das artes analógicas para a estrutura lógica e semântica do front-end.

## 🛠️ Tecnologias e Conceitos Aplicados

Neste projeto específico, foquei em exercitar:
* **HTML5 Semântico:** Estruturação lógica de seções, agrupamento de mídias e tratamento de formulários.
* **CSS3:** Criação de layout responsivo, estilização personalizada e consistência de componentes visuais.
* **UI/UX Design:** Harmonização entre paleta de cores neutras (focadas em dar destaque às obras de arte), tipografia com alta legibilidade e hierarquia de informação estruturada.

---

## 📁 Estrutura de Arquivos Destacada

A organização arquitetural do diretório reflete a preocupação com a componentização e clareza para manutenção técnica:
* `/assets`: Diretório centralizador de recursos globais, subdividido rigidamente entre `/css` (estilos) e `/img` (mídias do acervo).
* `projetofinal.html`: Página principal (*Home*) que atua como a vitrine do portfólio.
* `perfil.html`: Página institucional contendo o perfil biográfico e a trajetória acadêmica da autora.
* `cadastro.html`: Fluxo simulado de entrada e autenticação de usuários interessados no acervo.
* `aviso.html`: Página estratégica de tratamento de rotas não implementadas (informa o usuário de forma amigável que certas ações de botões pertencem a escopos futuros do projeto).
